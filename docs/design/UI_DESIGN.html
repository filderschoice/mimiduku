1. 概要と読み方

アプリのUIは「アプリ内の画面（Jetpack Compose）」と「アクセシビリティサービスが他アプリの上に重ねるオーバーレイ（View）」の2系統です。

この資料の画像について：リポジトリに画像資産（スクリーンショット）は無く、実機キャプチャも未取得です。 本書の画面は 実装コード（Compose・レイアウトXML・strings.xml・VectorDrawable）から文言・寸法・色を転記して HTML/SVG で再現したもので、 フォントの字形、上部バーのアイコン（歯車・「⋮」は文字で近似）、端末ごとの描画差は反映されません。 みみづくのイラストは VectorDrawable のパスをそのまま SVG 化しているため、形・色は実物と一致します。

設計の方針（コードから読み取れるもの）

  • こどもモード：ひらがな中心・怖がらせない・短い文言
  • おとなモード：通常の文言で検知理由を具体的に提示
  • 警告文言はすべて strings.xml に集約し差し替え可能
  • 画面上の文字は照合にのみ使い、保存・送信しない（開示画面で明示）
  • アプリ内はネイビー基調のブランド配色で、端末のダーク設定に追従

UI構成要素

  • ホーム（HomeScreen）：状態・一時停止・ログ件数。上部バーに歯車と「⋮」
  • 設定（SettingsScreen）：利用モード・PIN・バッジ
  • このアプリについて（AboutScreen）：開示文とログの扱い
  • ログ画面（LogScreen）／PINダイアログ（入力／設定）
  • オーバーレイ：警告バナー（上）・広告案内パネル（下）・タップシールド・バッジ（右端）

配布の2版

  • GitHub版全機能
  • Play版Google Play ポリシー対策で一部のUI・介入を無効化
  • 同一ソース。差は FeatureSet に集約（9章）

ナビゲーションライブラリは使わず、SettingsController の状態（screen / logRows / dialog）で切り替えます。画面間の移動の操作は NavigationActions に分けています。

3. ホーム・設定・このアプリについて

各画面は上部バー（TopAppBar）と縦スクロールの本文（余白16dp、カード間16dp）の共通の枠（AppScaffold）です。ホームは歯車（設定）と「⋮」メニュー、それ以外は戻る矢印を持ちます。画面はスクロール全体を展開して描いています。

5. 保護者 PIN ダイアログ

Material3 の AlertDialog。入力は数字のみ・最大8桁・マスク表示（NumberPassword）。形式は4〜8桁。

6. 警告オーバーレイ

すべて TYPE_ACCESSIBILITY_OVERLAY。フォーカスを取らず、バナー／パネルは自身の領域のタッチだけを受け取る（FLAG_NOT_TOUCH_MODAL）。

6.1 画面への重なり方

広告画面の案内パネル・シールド・「もどる」での閉じるボタン代理タップは GitHub版のみ。Play 版では出ません。

6.2 警告バナーの全文言パターン

モード × 検知の種類 × 版で決まる7パターン（BannerSpec.from）。灰色の帯は下地、バナー本体が実際のオーバーレイです。ボタンは白地に紺の文字（8章）。

7. みみづくバッジ・アプリアイコン

バッジは画面右端・縦中央に 44dp・不透明度85%で常駐し、タッチは下のアプリへ通す。絵は「仮の自作画像」で、同名の drawable を差し替えれば置き換わる設計。

SLEEPY
平常時。うとうと（目を閉じた弧）。羽角は短い。
ALERT
広告画面を見張っている。羽角が立ち、目が開く。GitHub版のみ
WIDE_EYED
危険度の高い検知の直後10秒間。目が大きくなる。

9. 版による UI の差分（GitHub版 / Play版）

差は FeatureSet に集約。Play の「他のアプリの広告表示の妨害」に当たり得る機能を外しています。

機能GitHub版Play版UIへの影響
外部遷移をこどもモードで自動で戻す✔—Play版はこどもでも「もどる／このまま すすむ」を出す。設定画面のこども説明も切替
タップ直後の外部遷移にも介入✔—バナーが出る機会が減る
広告画面の案内パネル（残り秒数・大きな「もどる」）✔—6.1 の下部パネルが出ない
全画面広告のタップシールド✔—暗幕が出ない
閉じるボタンの代理タップ✔—案内パネルの「もどる」が無いため UI としては現れない
バッジの「広告画面で耳が立つ」表情✔—ALERT 表情が使われない。設定画面のバッジ説明も切替
版ラベル（設定画面）GitHub 版（全機能）Google Play 版見出し直下に表示

共通: 偽の警告バナー・外部遷移（タップなし）への警告・開示と同意・PIN・一時停止・ログ・バッジ（SLEEPY／WIDE_EYED）。

10. 所見（デザイン上の論点）

コード読解から挙がった論点と、2026-10-20 の UI 整理後の状況です。実機で確認していないものは「未確認」としています。優先度付けや起票は含めていません。

#論点状況根拠・経緯
1配色がブランド色と不一致
配色		対応済みMimidukuTheme でネイビー #1E3A5F 基調の独自カラースキームを定義した。実機の見た目は未確認。
2ダークテーマ・ダイナミックカラー
テーマ		ダークは対応済み
ダイナミックカラーは使わない方針		端末のダーク設定に追従（Activity の下地も DayNight）。ダイナミックカラーはブランド色を保つため採用しない（ユーザー決定）。実機は未確認。
3オーバーレイのボタン配色
実機は未確認		対応済み主ボタンの背景（白）・文字色（#1E3A5F）・角丸を明示し、端末のテーマに依らないようにした。実機での視認性は未確認。
4バッジ画像が仮素材
素材		継続丸みのあるかわいい造形（丸い体・羽角・ほお・目のハイライト）へ描き直したが、ファイル内コメントのとおり仮の自作画像。位置は右端中央固定、44dp・不透明度85%。
5カード順
情報設計		対応済みホームに状態・ガイド・一時停止・ログを、設定に利用モード・PIN・バッジを分けた。サービス停止中は「オンにできないとき」が状態の直後に来る。
6アクセシビリティ（画面読み上げ・文字拡大・横向き・タブレット）
未確認		継続バッジは読み上げ対象外に設定済み。上部バーのアイコンには説明文（contentDescription）を付けた。バナーの読み上げ、フォント拡大時のバナー高さ、横向き・タブレットでの崩れは未検証。
7こども向け文言の読みやすさ
文言		一部対応Play版の確認文を「おしていないなら「もどる」を おしてね。わからなければ パパ・ママに きいてね。」へ短くした。設定画面は保護者向けで漢字表記のまま。
8ストア掲載用スクリーンショット・実機キャプチャが未作成
素材		継続リポジトリに画像資産なし。本書のモックは再現であり、掲載用には実機撮影が必要。
