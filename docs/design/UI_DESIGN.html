1. 概要と読み方

アプリのUIは「アプリ内の設定画面（Jetpack Compose）」と「アクセシビリティサービスが他アプリの上に重ねるオーバーレイ（View）」の2系統です。

この資料の画像について：リポジトリに画像資産（スクリーンショット・書き出し済みアイコン）は無く、実機キャプチャも未取得です。 本書の画面は 実装コード（Compose・レイアウトXML・strings.xml・VectorDrawable）から文言・寸法・色を転記して HTML/SVG で再現したもので、 フォントの字形や端末ごとの描画差は反映されません。みみづくのイラストは VectorDrawable のパスをそのまま SVG 化しているため、形・色は実物と一致します。

設計の方針（コードから読み取れるもの）

  • こどもモード：ひらがな中心・怖がらせない・短い文言
  • おとなモード：通常の文言で検知理由を具体的に提示
  • 警告文言はすべて strings.xml に集約し差し替え可能
  • 画面上の文字は照合にのみ使い、保存・送信しない（開示画面で明示）

UI構成要素

  • 設定画面（SettingsScreen）：縦スクロールのカード列
  • ログ画面（LogScreen）：設定画面と差し替え表示
  • PINダイアログ（入力／設定）
  • オーバーレイ：警告バナー（上）・広告案内パネル（下）・タップシールド・バッジ（右端）

配布の2版

  • GitHub版全機能
  • Play版Google Play ポリシー対策で一部のUI・介入を無効化
  • 同一ソース。差は FeatureSet に集約（9章）

5. 保護者 PIN ダイアログ

Material3 の AlertDialog。入力は数字のみ・最大8桁・マスク表示（NumberPassword）。形式は4〜8桁。

6. 警告オーバーレイ

すべて TYPE_ACCESSIBILITY_OVERLAY。フォーカスを取らず、バナー／パネルは自身の領域のタッチだけを受け取る（FLAG_NOT_TOUCH_MODAL）。

6.1 画面への重なり方

広告画面の案内パネル・シールド・「もどる」での閉じるボタン代理タップは GitHub版のみ。Play 版では出ません。

6.2 警告バナーの全文言パターン

モード × 検知の種類 × 版で決まる7パターン（BannerSpec.from）。灰色の帯は下地、バナー本体が実際のオーバーレイです。ボタン配色は後述の所見を参照。

7. みみづくバッジ・アプリアイコン

9. 版による UI の差分（GitHub版 / Play版）

差は FeatureSet に集約。Play の「他のアプリの広告表示の妨害」に当たり得る機能を外しています。

機能GitHub版Play版UIへの影響
外部遷移をこどもモードで自動で戻す✔—Play版はこどもでも「もどる／このまま すすむ」を出す。設定画面のこども説明も切替
タップ直後の外部遷移にも介入✔—バナーが出る機会が減る
広告画面の案内パネル（残り秒数・大きな「もどる」）✔—6.1 の下部パネルが出ない
全画面広告のタップシールド✔—暗幕が出ない
閉じるボタンの代理タップ✔—案内パネルの「もどる」が無いため UI としては現れない
バッジの「広告画面で耳が立つ」表情✔—ALERT 表情が使われない。設定画面のバッジ説明も切替
版ラベル（設定画面）GitHub 版（全機能）Google Play 版見出し直下に表示

共通: 偽の警告バナー・外部遷移（タップなし）への警告・開示と同意・PIN・一時停止・ログ・バッジ（SLEEPY／WIDE_EYED）。

10. 所見（デザイン上の論点）

コード読解から挙がった論点です。実機で確認していないものは「未確認」としています。優先度付けや起票は含めていません。

#論点根拠・状況
1配色がブランド色と不一致
配色		アイコン・オーバーレイはネイビー #1E3A5F だが、設定画面は Material3 既定の紫（primary #6750A4）。独自テーマ未定義。
2ダークテーマ・ダイナミックカラー非対応
テーマ		MaterialTheme { } を引数なしで使用。既定は常にライト配色のため、端末がダークでも設定画面は明るいまま（実機は未確認）。
3オーバーレイのボタン配色が既定任せ
未確認		banner_primary は android:Button の既定スタイルで、文字色指定なし。サービスのコンテキストのテーマ次第で、ネイビー背景上の視認性が変わる可能性。本書のボタンは仮の配色で描画。
4バッジ画像が仮素材
素材		ファイル内コメントに「仮の自作画像」と明記。位置は右端中央固定で利用者は変更不可、44dp・不透明度85%。
5設定画面のカード順
情報設計		状態→一時停止→（ガイド）→モード→PIN→バッジ→ログ。サービス停止中は「一時停止」が「オンにできないとき」ガイドより先に来る。
6アクセシビリティ（画面読み上げ・文字拡大・横向き・タブレット）
未確認		バッジは読み上げ対象外に設定済み。バナーの読み上げ、フォント拡大時のバナー高さ（wrap_content）や、横向き・タブレットでの崩れは未検証。
7こども向け文言の読みやすさ
文言		バナー・案内パネルはひらがな中心だが、Play版の確認文は文が長い（「じぶんで おしたのでなければ…」）。設定画面は保護者向けで漢字表記。
8ストア掲載用スクリーンショット・実機キャプチャが未作成
素材		リポジトリに画像資産なし。本書のモックは再現であり、掲載用には実機撮影が必要。
