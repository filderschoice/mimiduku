## 書き方の注意

- 「広告ブロッカー」「広告を消す」とは書かない。本アプリは広告を消さず、他のアプリの広告表示を妨げない。
- 「悪質な広告（偽の警告・勝手な移動）への対策」であることと、ユーザー補助機能を使う理由を明記する。
- 子供向けアプリとして登録しない（対象は保護者と大人の利用者）。
- GitHub 版（全機能）の APK へのリンクは載せない。

## アプリ名（30文字以内）

みみづく - 偽の警告・勝手な移動に気づく見張り番

## 簡単な説明（80文字以内）

「ウイルスに感染」などの偽の警告や、広告による勝手なブラウザ・ストアへの移動に気づいて知らせます。

## 詳しい説明

みみづくは、スマートフォンの画面の端に止まって見張り、悪質な広告に気づいて知らせるアプリです。
子供の端末を守るために作りましたが、大人も使えます。

■ できること

- 偽の警告に気づく：「ウイルスに感染しています」「バッテリーが損傷しています」などの、広告によくある偽の警告を見つけて、
  「偽の警告の可能性があります」と知らせます。
- 勝手な移動に気づく：アプリを使っている最中に、タップしていないのにブラウザや Play ストアが勝手に開いたときに知らせ、
  「戻る」か「このまま進む」を選べます。
- 保護者 PIN：大人向けの設定への切り替えや一時停止を、PIN で守れます。
- 検知の記録：いつ、どのアプリで何に気づいたかを、端末の中に記録して確認できます。

■ できないこと

- 広告を消したり、ブロックしたりはしません。通常の広告の表示やクリックには介入しません。

■ ユーザー補助機能（アクセシビリティ サービス）の使用について

みみづくは、偽の警告の文言と勝手な移動を見つけるために、Android のユーザー補助機能を使って、前面のアプリの名前と
画面の文字を読み取ります。読み取った文字はその場の照合にだけ使い、保存も送信もしません。
本アプリはインターネットへ接続する権限を持たず、情報を外部へ送ることはありません。
最初に起動したときにアプリ内で説明を表示し、同意したときだけ使います。

## Play Console の申告で使う要点

| 項目 | 回答の要点 |
| --- | --- |
| アクセシビリティ API の用途 | 悪質な広告（偽の警告の文言・タップなしの外部遷移）を検知し、利用者へ知らせる。支援技術ではないため isAccessibilityTool は宣言しない |
| 開示を映した動画 | 初回起動 → 開示（はじめに：画面の読み取りについて）→ チェック → 同意して進む → アクセシビリティ設定 の流れを撮る |
| データセーフティ | 収集なし・共有なし（端末の外へ送信しない）。端末内に検知の記録を保存する |
| 対象年齢 | 保護者・大人（子供向けアプリとしない） |
| isMonitoringTool | 送信を伴う監視ではないため不要と見ている（DISTRIBUTION.md 6章の未確認点） |
