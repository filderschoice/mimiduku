# みみづく（mimiduku）プライバシーポリシー

制定日：2026-11-22

みみづく（以下「本アプリ」）は、Android 端末に表示される悪質な広告（偽の警告、勝手なブラウザ・ストアへの移動など）を
見つけて知らせるアプリです。本アプリが扱う情報と、その扱い方を次のとおり定めます。

## 1. 本アプリが読み取る情報

本アプリは Android のユーザー補助機能（アクセシビリティ サービス）を使い、次の情報を読み取ります。

| 読み取る情報 | 使い道 |
| --- | --- |
| 前面に表示されているアプリのパッケージ名と画面の種類（クラス名） | 勝手な外部への移動の検知、広告の画面かどうかの判定 |
| 画面に表示されている文字 | 偽の警告の文言（「ウイルスに感染しています」など）や、広告の表示（「スキップ」など）の照合 |
| 画面に表示されているボタンの位置（GitHub 版のみ） | 利用者が「もどる」を押したときに、広告の本物の閉じるボタンを押すため |
| 画面のタップの有無（タップがあった時刻） | 利用者の操作による移動か、勝手な移動かの区別 |
| ブラウザのアドレスバーに表示されているサイト名（ドメイン）。「今後は確認しない」でサイトを登録している場合だけ | 登録済みのサイトか照合し、確認を省くため |

画面の文字とボタンの位置は、照合と操作のためにその場でだけ使い、保存しません。

利用者が本アプリ内の説明を確認して同意するまで、本アプリはこれらの情報を読み取りません。

## 2. 端末内に保存する情報

| 保存する情報 | 目的 | 保存場所 |
| --- | --- | --- |
| 検知の記録（日時、アプリのパッケージ名、検知の種類、照合したルールの ID、行った介入、直前のタップの有無、利用モード） | 保護者・利用者が検知の履歴を確認するため | 本アプリ専用の領域（他のアプリからは読めない）。最新500件まで |
| 確認を省く対象（アプリのパッケージ名、サイト名のハッシュ値と PIN で暗号化した控え） | 保護者が信頼するアプリ・サイトで確認を出さないため | 同上。各50件まで |
| 設定（利用モード、保護者 PIN のハッシュ値、一時停止の期限、バッジの表示・位置・通知の設定、同意の記録） | 本アプリの動作のため | 同上 |

- 画面の文字、URL、入力した文字は保存しません。ただし、保護者が「今後は確認しない」で登録したサイトだけは、サイト名（ドメイン）を、照合用のハッシュ値（端末ごとのランダムな値を混ぜたもの）と、
  保護者 PIN から導いた鍵で暗号化した控え（AES-256-GCM）にしてだけ保存します。パス・検索語・ページの内容は読みません。保存したサイト名の一覧は、
  PIN を入力したときだけ復号して表示します。PIN は 4〜8 桁のため、保存データを端末から取り出せる相手には総当たりで復号されうる強度です。PIN を削除するとサイトの登録はすべて消え、
  PIN を変更すると新しい PIN で暗号化し直します。登録は設定画面からいつでも外せます。
- 保護者 PIN は元に戻せない形（塩つきのハッシュ値）でだけ保存し、PIN そのものは保存しません。
- 保存した情報は、端末のバックアップと、機種変更時のデータの移行の対象から外しています。
- 検知の記録は、本アプリの設定画面からいつでも消去できます。本アプリをアンインストールすると、すべて消えます。

## 3. 外部への送信と第三者への提供

本アプリはインターネットへ接続する権限を持たないため、読み取った情報や保存した情報を外部へ送信しません。
「このアプリについて」の「開発ページを開く」を押したときは、端末のブラウザが GitHub のページを開きます（アプリ自身は通信せず、開く前に情報を付け加えません）。
第三者への提供も行いません。本アプリには広告や、利用状況を収集する仕組み（解析ツール）を組み込んでいません。

## 4. 子供の情報

本アプリは、保護者が子供の端末に入れて使うことを想定しています。子供の情報を含め、本アプリが扱う情報は
1章・2章のとおり端末の中だけで扱い、外部へ送信しません。

## 5. ユーザー補助機能をやめる方法

端末の「設定」→「ユーザー補助」から、本アプリをいつでもオフにできます。オフにすると、本アプリは情報を読み取りません。

## 6. 版による違い

本アプリには GitHub で配布する版（全機能）と Google Play で配布する版（機能限定）があります。
Google Play 版は、広告の画面かどうかの判定（1章の表の「広告の表示」の照合と、画面の種類による判定）と、ボタンの位置の
読み取り（1章の表の3行目）を行いません。それ以外の情報の扱いは同じです。

## 7. 改定

本ポリシーを改定する場合は、本ページで知らせます。読み取る情報や使い道を変える場合は、本アプリ内で改めて同意を求めます。

## 8. 問い合わせ先

本ポリシーやアプリについてのご質問・ご意見は、GitHub の Issues（<https://github.com/filderschoice/mimiduku/issues>）で受け付けます。
Issues は誰でも読めるため、氏名・連絡先・端末内の画面の文字など個人情報を書かないでください。
