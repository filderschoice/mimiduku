## 2. 実機での確認（人手検証。BL-009 は完了）

自動化できないため、人が実機で確認します。結果は「4. 記録欄」に書きます（BL-009 は 2026-11-23 にユーザーの判断で完了として BACKLOG から削除済み）。

### 2.1 注意事項

- **実際の広告はクリックしないでください。** 広告のクリックや完了の偽装はクリック詐欺に当たるため、
  本手順では adb やメモアプリで同じ状況を再現します。
- 端末は可能なら Android 10・13・14 以降の3世代、ジェスチャーナビと3ボタンナビの両方で確認します。

### 2.2 準備

1. README の「インストール」の手順で debug 版を入れ、アクセシビリティをオンにします。
2. アプリを開き、「見張っています」と表示されることを確認します。
3. スケアウェア文言の確認（T9〜T11）では、リポジトリ内のテストページ `tools/verification/scareware-page/` を PC から配信し、
   端末の Chrome で開きます。ページは架空の文言だけで外部へ通信せず、APK には入りません。PC の自分自身（127.0.0.1）だけで
   待ち受け、USB 接続の端末から `adb reverse` で届けます（同じ Wi-Fi の他の機器からは開けません）。

   ```sh
   python -m http.server 8000 --bind 127.0.0.1 --directory tools/verification/scareware-page
   adb reverse tcp:8000 tcp:8000
   ```

   端末の Chrome で `http://localhost:8000/` を開くと、読み込み直後に警告の文言が出るページ（T9）が開きます。
   同じページのリンクから、警告の無いページ（T11 のバナーの外のタップ先）と、下までスクロールすると文言が出るページへ移れます。
   確認が終わったら、サーバーを Ctrl+C で止め、`adb reverse --remove tcp:8000` で転送を外します。
   ページの本文が検知の対象になることは単体テスト `ScarewarePageTest` で確かめています。
